Ubuntu 25.04 KiCad stage: before and after

Scope: actual Bash functions sourced from Ubuntu/install-eSim-scripts/install-eSim-25.04.sh, not a simulation or a full dispatcher/GUI test. Two disposable linux/amd64 ubuntu:25.04 containers (image ID prefix 27771fb7b40a), root, signed Ubuntu indexes using /usr/share/keyrings/ubuntu-archive-keyring.gpg. http://old-releases.ubuntu.com/ubuntu returned 404 for plucky Release; http://archive.ubuntu.com/ubuntu supplied signed plucky, plucky-updates, plucky-security and plucky-backports. Mirror setup was container-only, not an installer change. Both containers removed afterwards.

Control: a separate container with software-properties-common installed ran the same old function.
